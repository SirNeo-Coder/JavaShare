WEDNESDAY Pick Exactly What to Style: Class and ID Selectors

Know: Distinguish element, class and ID selectors and tell which one wins on the same element.

Value: Choose class and id names that say what they mean.

Do: Style Juan's project badges with a class and his contact note with an ID.

Today's starting point: Element selectors style every h1 or every nav. Juan wants to style only some elements: two project badges, one sentence.
Class and ID selectors. A class selector starts with a dot: .badge matches every element with class="badge", and many elements may share a class. An ID selector starts with #: #form-note matches the one element with id="form-note"; an id is used only once on a page. Class and id names are case-sensitive. On one element an ID rule beats a class rule, and a class rule beats an element rule.
ANALOGY At a school program, "Grade 11, stand" calls every student in the grade (an element), "Science club members, stand" calls a group that can be anywhere (a class), and "the student in seat 12, stand" calls one person (an id).
On one element, these rules set its colourThe winner

STEP 5 · projects.html, contact.html, styles.css · run page: projects.html

A class selector starts with a dot and matches every element with that class. This step adds a .badge rule to styles.css and gives two span elements class="badge", one after each project. Run it unchanged: both badges are small, yellow and in capitals.

styles.css · new lines at the end

/* Class selector: every element with class="badge" */
.badge {
  background-color: #fff3c4;
  font-size: 12px;
  text-transform: uppercase;
}

projects.html · the two changed lines in the list

    <li>Science poster: Saving water at home <span class="badge">solo work</span></li>
    <li>Comic strip for Filipino class: Bayanihan in our barangay <span class="badge">group work</span></li>

STEP 6 · contact.html, styles.css · run page: contact.html

An ID selector starts with # and matches the one element with that id. This step moves the inline style of the prototype sentence into styles.css as #form-note, and adds a p rule that makes every paragraph dark grey. Run it unchanged: the sentence is still red and bold.

styles.css · new lines at the end

/* Element selector: every paragraph */
p {
  color: #333333;
}

/* ID selector: only the element with id="form-note" */
#form-note {
  color: #9b1c1c;
  font-weight: bold;
}

contact.html · the inline style is replaced by an id

<p id="form-note">This form is a prototype: it sends nowhere.</p>

Practice: which colour wins? A paragraph has class c and id i. The rules are p navy, .c maroon and #i red. (a) as written; (b) with a style attribute that says orange; (c) without the id. Answers: (a) red: an ID beats a class and an element; (b) orange: inline beats them all; (c) maroon: a class beats an element.
