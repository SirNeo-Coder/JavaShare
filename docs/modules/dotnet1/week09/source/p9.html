Week 09 practice tasks

.NET 1 · Flexbox and Media Queries · One small task for every step, in CodeShare

How to do each task. In CodeShare, Work in code editor loads the step's sample. Run it unchanged first: Sample verified saves that check but does not complete the step. Then make the small change in Your task and Run code again. Matching the Expected task output shows Completed, saves your progress and opens the next step. Reopening a started step restores your saved edits. Spaces and line breaks count. In an output box, an indented line continues the line above it.
Weeks are linked. CodeShare opens this week only after every Week 8 task is Completed. Your module project and personal performance-task project carry forward from Week 8.
Run page and styles.css. Each step heading on pages 1–6 names its run page; its task output is the text of that page. Flexbox and media queries move boxes, so most tasks add an element to change words you can see; Step 4 and Step 8 change the output by themselves. The output is the same at every width. Only Steps 1, 3, 4, 5, 8 and 9 have Media checks.
