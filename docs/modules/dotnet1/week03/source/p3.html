TUESDAY There and Back: Linking Juan's Pages Both Ways

Know: Explain how the pages of one project link to each other both ways with href values that name a page.

Value: Respect readers' time by giving every page a way back.

Do: Link Juan's three pages both ways with the same navigation bar and test every link in the page window.

Today's starting point: Monday's links go one way only: projects.html has no way back, and contact.html has no links at all.
Links between pages. href="projects.html" opens projects.html, a page of the same project. Two pages are linked both ways when each has a link to the other. A navigation bar (nav) is the same group of links at the top of every page. Link text says where the link goes; never write click here.
ANALOGY A jeepney signboard names both ends of its route, so riders know they can go there and come back. Pages linked both ways are a route with a way back.

WEDNESDAY A Page in a Page and a Form with Labels: Frames and Fields

Know: Explain the iframe attributes and the label, input, select and textarea fields with their type, name, id, for, required and placeholder attributes.

Value: Ask visitors only for the data that is needed, with honest labels.

Do: Show Juan's contact page in a frame and build his labelled contact form.

Today's starting point: The pages are linked, but a reader must leave the projects page to reach the form, and the form asks only for a name.
Frames and form fields. On an iframe, src names the page to show, title tells screen readers what it holds, and width and height set its size in pixels (300 by 150 if left out). In a form, a label's for matches the id of its box; name names the data; type="email" expects an email address; required means the box may not be empty; placeholder is a hint inside the box; select holds a list of option choices; textarea is a box of several lines.
ANALOGY A barangay bulletin board pins a copy of a notice inside a frame. A barangay clearance request has labelled blanks, a list of purposes to choose from and a space for remarks.
