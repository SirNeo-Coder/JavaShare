MONDAY Meet HTML: Juan Dela Cruz's First Resume Page

Know: Explain the role and versions of HTML and the parts of a page: doctype, html, head, title, body, elements, attributes and values.

Value: Show care for privacy by putting only safe, made-up details on a sample resume page.

Do: Run Juan's first resume page in CodeShare's code editor and add a paragraph to its body.

Week 1 starts here: Plain words with no HTML run together: a name, an introduction and skills typed in body appear on one line.
HTML. HTML (HyperText Markup Language) gives a web page its meaning and structure: headings, paragraphs and lists. CSS, from Week 4, changes how it looks. A web editor is where you write HTML; in this course it is CodeShare's code editor, and Run code shows the page in the page window.
ANALOGY A printed resume has a name at the top, a short introduction and lists. HTML labels each part so the browser, and a screen reader, know which part is which.

STEP 1 · index.html

Open Step 1 and press Work in code editor: CodeShare puts Juan's first page in index.html. Press Run code without changing anything. Then read the code from the top: the doctype, html with lang="en", head with meta and title, and body with h1 and p.

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Resume of Juan Dela Cruz</title>
</head>
<body>
  <h1>Juan Dela Cruz</h1>
  <p>Hello! I am Juan Dela Cruz,
  a senior high school student in the ICT strand.</p>
</body>
</html>

WhenHTML
1990–1995The first HTML; many revisions and additions in its first five years.
1997HTML 3.2, then HTML4 the same year (W3C).
2000XHTML 1.0: HTML4 rewritten in the stricter XML style.
2004 onwardWork on HTML5 begins, led by browser makers (WHATWG).
2019 to todayW3C and WHATWG agree on one HTML: the HTML Living Standard. The doctype line means today's HTML.
Syntax: an element is an opening tag, its content and a closing tag. An attribute such as lang="en" sits in the opening tag; "en" is its value. Elements nest: the inner one closes first. br and hr have no closing tag.
