TUESDAY Inline, Internal, External: Moving Juan's Styles into One Stylesheet

Know: Explain which rule wins when inline, internal and external CSS set the same property.

Value: Appreciate one tidy shared stylesheet that classmates can read and change.

Do: Move Juan's rules into styles.css and link it from all three pages.

Today's starting point: Monday's styles stay where they were written: the style element styles only index.html, and the inline style only one sentence.
Which rule wins. When two rules give one element different values for the same property, an inline style wins over rules in a style element or a stylesheet. Between two rules of the same kind, the later one wins, so the order of the style element and the link line matters. An external stylesheet is one .css file; each page links it with a link element in head: rel="stylesheet" and href="styles.css", each value in quotes.
