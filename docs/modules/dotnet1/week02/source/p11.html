Discussion

  • Look at line 77. </table> ends Monday's table. The sound comes after it.
  • Look at line 78. <h2>Sound greeting</h2> is a section heading, like Week 1's.
  • Look at line 79. <audio src="audio/greeting.wav" controls></audio> uses audio to play a sound. src names the file in the audio folder; controls shows a play button.
  • The sound has no page text. Its line in Media checks says whether the file plays. People who cannot hear it need words: that is today's change.
  • The output ends with Media checks:, one line per picture, sound or video: whether the file loaded. Media are not page text.
