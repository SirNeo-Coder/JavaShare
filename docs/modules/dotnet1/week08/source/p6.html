Performance task · My Resume, Week 8: Hover, Focus and a Pseudo-element · 50 points

Start Thursday; finish and present Friday. In CodeShare open Projects, then Personal performance-task project. Your Week 7 site carries forward: add this week's rules to your own styles.css.

Give your links and skill items a hover state, and give every link and button a focus state that is as easy to see as hover: the same colours for :focus, and a :focus-visible outline. Add one structural pseudo-class, such as :first-child on your skills, and at least one pseudo-element: a short symbol with ::before or ::after (content in quotes), or a ::first-letter drop cap. Text added with content is decoration: it is not page text and some screen readers skip it, so keep every word a visitor needs in the HTML. Test with the mouse and with the Tab key in the page window. Hover, focus and pseudo-elements work the same online and offline; offline your gallery pictures still show only their alt text until you add them online.

Use only safe details: no home address, phone number, birth date, ID numbers or personal social-media accounts, and no other people in any picture. Run code until index.html runs with no error, then press Submit this version. Saving or running is not submitting.
