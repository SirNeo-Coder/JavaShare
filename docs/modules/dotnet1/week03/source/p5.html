Know: Locate a missing quote and an unclosed textarea by comparing the output with the code.

Value: Show patience and care when checking every quote and tag.

Do: Repair a broken link and a broken form, then begin the personal resume additions.

Today's starting point: Browsers show no error for a missing quote or a missing closing tag: words just vanish from the page.
Repairing links and forms. An attribute value runs from its opening quote to the next quote, so a missing quote swallows the code after it. A textarea needs its closing tag; until it is closed, everything after it becomes the box's text.
ANALOGY A text message that opens a quotation mark and never closes it makes everything after it look like part of the quote. A missing quote in HTML does the same.

If you see…It means…Fix it by…
A link's word and the heading after it vanish; the next words join the link's line.An href lost its closing quote.Put the quote back: href="contact.html">.
Everything after the message box vanishes.The textarea has no </textarea>.Close it right after its opening tag.
The page window says: This project has no page named Projects.html.The href does not match the page's name exactly; capital letters count.Copy the name exactly: projects.html.
Links outside this project do not open in CodeShare.The href leads to the internet.In class, link only to the project's own pages.
What you typed in a box, or a placeholder, is not in the output.Typed words and placeholders are not page text.Check the labels; the page checks look at the boxes.
The framed page's words are not in the output.A frame's page is a different page.Run that page in its own step, or open it with a link.
