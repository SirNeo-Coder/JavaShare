Know: Explain :hover, :focus, :focus-visible, :required and :nth-child(), and why focus must be as easy to see as hover.

Value: Appreciate visitors who use only the keyboard.

Do: Give Juan's form, button, links and goals their states and test them with the mouse and the Tab key.

Today's starting point: Juan's first skill stands out and each badge has one capital, but his form, button and goals look the same whatever you do.
States of links, buttons, form boxes and lists. :hover needs a mouse, so give every link and button :focus too, just as easy to see; :focus-visible shows an outline when the keyboard reaches a link. :required picks boxes that must be filled, :nth-child(odd) the 1st, 3rd, 5th items. Page checks read these structural and form pseudo-classes, never hover or focus: a check has no mouse or keyboard.
ANALOGY An elevator button lights up when it is pressed with a finger or reached any other way; a good page lights up a link for the mouse and for the keyboard alike.

STEP 3 · contact.html, styles.css · run page: contact.html

Pseudo-classes on a form. input:required gives every box that must be filled a maroon border. The box you click or Tab into gets a 3px maroon outline with :focus, and the button turns white on maroon with button:hover and button:focus, so the keyboard sees what the mouse sees. Run contact.html unchanged.

styles.css · three new rules (end of the file)

/* Pseudo-classes on the form: every box that must be filled has a maroon border */
input:required {
  border-color: #8a1c55;
}

/* The box you click or Tab into gets a maroon outline */
input:focus, select:focus, textarea:focus {
  outline: 3px solid #8a1c55;
}

/* The button: white on maroon under the mouse and the keyboard alike */
button:hover, button:focus {
  color: #ffffff;
  background-color: #8a1c55;
}

Links and lists. a:focus-visible draws a 3px maroon outline, 2px outside a link, when the keyboard reaches it, as easy to see as the hover colour. The goals list gets class="goals", and .goals li:nth-child(odd) colours its 1st, 3rd and 5th goals maroon. Run index.html unchanged.

styles.css · two new rules (end of the file)

/* Links: a maroon outline when the keyboard reaches a link, as easy to see as the hover colour */
a:focus-visible {
  outline: 3px solid #8a1c55;
  outline-offset: 2px;
}

/* Lists: the 1st, 3rd, 5th ... goal in maroon */
.goals li:nth-child(odd) {
  color: #8a1c55;
}
