THURSDAY Every Width Checked, Then the Hardest Repair

Know: Recognise an invalid value, a missing bracket, a query with no unit and a picture that overflows.

Value: Show patience when one missing bracket undoes the rest of a stylesheet.

Do: Lay the two tables out in a grid, repair the broken gallery rule, and finish the personal resume.

Today's starting point: Juan's two tables each take a whole page width, and a missing bracket would be invisible to him.
Layout repairs. An invalid value such as display: gird drops only its own declaration. A grid property written on the items instead of the container does nothing. A missing bracket is worse: the value is never finished, so everything after it is swallowed. @media (max-width: 900), with no unit, is dropped whole. A picture with a fixed width wider than the page makes the page scroll sideways.
ANALOGY An announcement on the barangay bulletin board that stops in the middle of a sentence: everything written after it is lost too, because nobody can tell where the first notice ended.

Problem guide

If you see…It means…Fix it by…
The grid does nothing and the gap is ignored.display: grid is missing or misspelt (display: gird).Write display: grid; on the container.
Everything after one rule stopped working.A bracket was never closed, so the rest was swallowed.Close it; read up from the first rule that still works.
A whole media query does nothing at any width.A length with no unit: @media (max-width: 900).Write the unit: (max-width: 900px).
The page scrolls sideways; a picture sticks out.A picture wider than the page, with no max-width.Add max-width: 100%; and height: auto;.
Practice: in styles.css, (a) write display: gird; in .tables; (b) write @media (max-width: 900) with no px. Answers: (a) that line alone is dropped; (b) the whole query is dropped, at every width. Undo both.
