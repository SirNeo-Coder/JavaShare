Week 07 practice tasks

.NET 1 · Position, Z-index, Float and an Image Gallery · One small task for every step, in CodeShare

How to do each task. In CodeShare, Work in code editor loads the step's sample. Run it unchanged first: Sample verified saves that check but does not complete the step. Then make the small change in Your task and Run code again. Matching the Expected task output shows Completed, saves your progress and opens the next step. Reopening a started step restores your saved edits. Spaces and line breaks count. In an output box, an indented line continues the line above it.
Weeks are linked. CodeShare opens this week only after every Week 6 task is Completed. Your module project and personal performance-task project carry forward from Week 6.
Run page and styles.css. Each step heading on pages 1–6 names its run page; the expected task output is the page text of that page. position, offsets, z-index and float are not page text, but a box taken out of the flow with position: absolute or float gets its words on their own line. Captions are page text; alt is not. Only Steps 2, 4, 5, 6 and 9 have Media checks.
