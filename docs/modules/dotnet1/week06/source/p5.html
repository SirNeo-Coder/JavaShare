Problem guide

If you see…It means…Fix it by…
A padding, margin or border you wrote has no effect.The value is invalid, so the whole declaration is skipped: a number with no unit (padding: 10), a space before the unit (1.5 em), a misspelt property (pading) or a negative padding.Write the unit right after the number (10px, 1.5em) and spell the property exactly; padding is never negative.
A border does not show.It has no style: border: 2px #13305c; reads style none.Add a style: border: 2px solid #13305c;.
The nav bar falls onto three lines.display was skipped: the ; before it is missing, or display is misspelt.End every declaration with ;: margin-right: 0.5em;.
Every rule after one point stops: the nav loses its capitals and its bullets come back.A } is missing, so the rest of the file is read inside that rule.Close every rule with } before the next selector.
The nav words run together: HOMEPROJECTSCONTACT.The li tags are typed on one line with no space between them.Put each li on its own line.
