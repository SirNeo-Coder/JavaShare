Today's starting point: Juan's interests written in one paragraph with commas are hard to scan, and Monday's goals list is only numbers.
Lists. ul groups items whose order does not matter (bullets); ol groups items whose order matters (numbers or letters). Each item is an li. On ol, type picks the markers (1, A, a, I, i), start picks the first number (always a whole number) and reversed counts down. A list can sit inside an li.
ANALOGY A jeepney signboard lists its stops in order: that is an ol. A sari-sari store sign lists what it sells in any order: that is a ul.
Attribute on olValuesExample
type1 (numbers, the default), A, a, I, itype="A" gives A, B, C
startA whole number, even with lettersstart="3" counts from 3
reversedNo value neededstart="3" reversed gives 3, 2, 1
