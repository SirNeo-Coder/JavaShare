Before you add styles.css

  • ☐ Press ＋ in your personal project and name the file exactly styles.css (letters, no spaces).
  • ☐ In head of every page, after the title, add the same line: <link rel="stylesheet" href="styles.css">, with its quotes.
  • ☐ Write each rule as selector { property: value; }, one declaration per line, every one ending with ;.
  • ☐ A class starts with a dot (.highlight) and may be used on many elements; an id starts with # and is used once.
  • ☐ Above each rule, a comment between /* and */ names its type: element, class or ID selector.
  • ☐ Only colours and fonts already on the computer; nothing named in url().
