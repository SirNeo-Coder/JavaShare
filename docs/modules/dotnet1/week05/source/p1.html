Text, font, colour, gradient and opacity. Text and font properties set how words look. font-family names a list of fonts tried in order, ending in a generic family (serif, sans-serif or monospace) that every computer has; font-size, font-weight and font-style set size, boldness and slant. color sets the text colour, written as a name (white), a hex code (#ffffff) or rgb(255, 255, 255). A gradient is a background image that blends colours: background-image: linear-gradient(to right, #13305c, #8a1c55). opacity fades a whole element, from 1 (solid) to 0 (invisible).
ANALOGY A Foundation Day tarpaulin: the letters, their size and their colours are chosen so people can read it from far away; a blended background looks good only if every word still stands out.
