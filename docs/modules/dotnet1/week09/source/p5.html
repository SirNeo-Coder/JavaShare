Know: Recognise a layout whose flex container was removed, and tell display: inline from a flex item.

Value: Show patience and care when three deleted lines change a whole layout.

Today's starting point: Three lines deleted from one rule can undo a whole layout, and the browser shows no error.
Layout repairs. If display: flex is missing or misspelt, there is no flex container: gap does nothing, flex-direction does nothing, and the items fall back to their own display. display: inline on a list item makes it run together with the next one like words, which does change the page text. A media query with no units, @media (max-width: 900), is dropped whole.

Problem guide

If you see…It means…Fix it by…
gap and flex-direction do nothing, and the items keep their old spacing.display: flex is missing or misspelt, so there is no flex container.Write display: flex; on the container, not on the items.
The list items run together on one line, in the page window and in the output.display: inline on the items, with no flex container above them.Delete that rule and put display: flex back on the container.
A whole media query does nothing at any width.A length has no unit: @media (max-width: 900) is dropped.Write the unit: @media (max-width: 900px).
The items are side by side when you wanted them stacked.flex-direction is row, which is what a flex container does by default.Add flex-direction: column; to the container.
An item that does not fit squeezes the others instead of moving down.flex-wrap is missing, so the row never breaks.Add flex-wrap: wrap; to the container.
Practice: in styles.css, (a) delete display: flex; from .skills but leave gap; (b) write @media (max-width: 900) with no px. Answers: (a) the gap does nothing and the output does not change; (b) the whole query is dropped, at every width. Undo each change.
