STEP 1 · index.html, styles.css · run page: index.html

Juan's Week 9 site carries forward. A grid view lays boxes out in rows and columns at once. display: grid makes a box a grid container and its children grid items; grid-template-columns: repeat(2, 1fr) asks for two columns, and the fr unit shares out the space that is left, so each takes one half. gap: 12px spaces the cells. Juan's gallery was a flex row that wrapped; now it is a grid of two equal columns, and each figure fills the column it is given. Run index.html unchanged.

styles.css · the gallery becomes a grid; the figure loses its own width

/* Grid view: two equal columns, 12px between the cells */
.gallery {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 12px;
}
/* The grid gives each figure its column, so no width here */
.gallery figure {
  position: relative;
}

STEP 2 · projects.html, contact.html, styles.css · run page: projects.html

A grid can also count its own columns. repeat(auto-fit, minmax(220px, 1fr)) means: fit as many columns as you can, each at least 220 pixels wide, and let each one share the space that is left. On a wide page that is three or four cards side by side; on a narrow page it is one. Juan's project cards were a flex column with a media query that turned them into a row; auto-fit does both jobs, so that whole media query is deleted from the end of styles.css. Run projects.html unchanged.

styles.css · the project cards become a grid that counts its own columns

/* Grid view: as many columns as fit, each at least 220px wide */
.project-list {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 12px;
  list-style-type: none;
  padding-left: 0;
}

Output (page text): the same as Juan's Week 9 projects page's output; a grid moves boxes and a resized picture has no words, so the page text does not change.

Answers: (a) no: a figure was already a box of its own; (b) no: spacing is not page text; (c) no: each figure keeps its own line; (d) yes: the letters themselves change.
Page checks and the width of the window: a page check reads a computed value, so it must be a value that is the same at every width. A column's real width is not: a track in fr, minmax() or auto-fit is worked out from the space there is, so it is never the same number twice. That is why the checks read display, the gap, max-width and the counts, never a column width, and why you test the width yourself by making the browser window narrower.
