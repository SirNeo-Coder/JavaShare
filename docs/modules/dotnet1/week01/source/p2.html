Part of the pageWhat it does
doctype lineSays the page uses today's HTML. Always the first line.
html with lang="en"Holds the whole page; lang says its language is English.
headInformation about the page; not shown on the page.
meta charset="utf-8"Lets the page show the letters of any language, such as ñ.
titleThe name on the tab: the Tab title line of the output.
bodyEverything shown on the page: the Visible page text.
h1, h2Main heading (one per page) and section headings.
pA paragraph. Line breaks and extra spaces in your code become one space.
commentA note for people, starting with <!-- and ending with -->. Never shown.
Element or attributeUse it forIn the page text
strong / emImportant words / stressed wordsThe words only
b / iWords set apart / a foreign word or termThe words only
mark / smallHighlighted words / side comment, small printThe words only
sub / supLowered / raised charactersJoined: H2O, 1st
brA line break inside a paragraphA new line
hrA change of topic (a line across)Nothing
preText whose spaces must staySpaces and lines kept
ul, ol, liBullet list, numbered list, one itemOne line per item, no markers
