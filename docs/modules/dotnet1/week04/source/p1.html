CSS. CSS (Cascading Style Sheets) sets how HTML elements look: colours, fonts, sizes and spacing. HTML says what the content is; CSS says how it looks. A rule is a selector and a declaration block: h1 { color: #13305c; }. Each declaration is a property, a colon, a value and a semicolon. CSS can be written in three places: inline (a style attribute on one element), internal (a style element in head) or external (a .css file the page links). A selector can name an element (h2), a class (.badge) or an id (#form-note).
ANALOGY A school uniform rule names who it is for (Grade 11 students: the selector) and what they wear (white polo: a property and its value). A note pinned to one student is inline; a rule posted in one classroom is internal; the school handbook every room follows is external.
