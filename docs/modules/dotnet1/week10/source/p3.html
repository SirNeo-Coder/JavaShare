TUESDAY Pictures and Video That Fit Any Width

Know: Explain why max-width: 100% with height: auto keeps a picture or video inside the page.

Value: Show care for classmates whose only computer is a phone with a small screen.

Do: Make Juan's banner, gallery pictures, profile picture and video resize in CodeShare.

Today's starting point: Juan's pictures and video have fixed widths, so a picture wider than the page would push the whole page sideways.
Responsive pictures and video. max-width: 100% means never wider than the box around it, and max-width overrides any width. height: auto lets the height follow the width, so the shape is kept. The width and height in the HTML stay the natural size. For one picture in several real sizes there are srcset and sizes, which name a file and its width in w units; this module uses one file per picture.
ANALOGY A tarpaulin for the barangay fiesta: the same design is printed smaller for a narrow wall, keeping its shape. One cut for a wide wall and nailed to a narrow one hangs over the edge: that is a picture with no max-width.

STEP 3 · index.html, styles.css · run page: index.html

A picture wider than the page pushes the whole page sideways. Juan's new banner is 900 pixels wide, so .banner gets max-width: 100%: never wider than the box it sits in. max-width overrides width, and the percentage is measured against that box; height: auto keeps the shape. The gallery pictures get the same two lines instead of a fixed width. Run index.html unchanged.

index.html · a new line under the h1

  <img class="banner" src="images/juan_banner.svg" alt="Resume banner drawn for Juan Dela Cruz" width="900" height="240">

styles.css · a new rule (end of the file)

/* Responsive picture: never wider than the box it is in */
.banner {
  max-width: 100%;
  height: auto;
}

styles.css · the changed .gallery img rule

/* Gallery: no picture wider than its column; the height follows */
.gallery img {
  max-width: 100%;
  height: auto;
  border: 1px solid #555555;
}

Video and other pictures take the same two lines. video, .profile gives both the video and Juan's own picture max-width: 100% and height: auto, so neither can be wider than the page and both keep their shape. The video keeps width="320" in the HTML: that is its natural size, and max-width only steps in when there is less room than that. Run index.html unchanged.

Practice: which line does what? (a) which one stops a picture being wider than its box; (b) which one keeps its shape; (c) which one tells the browser how much room to keep before the picture arrives; (d) which one offers the same picture in several real sizes. Answers: (a) max-width: 100%; (b) height: auto; (c) the width and height written in the HTML; (d) srcset with sizes.
