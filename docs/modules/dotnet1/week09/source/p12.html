Before you add your flex containers and your media query

  • ☐ display: flex goes on the container (the box that holds the items), never on the items themselves.
  • ☐ Choose flex-direction: row or column on purpose, and set the spacing with gap, not a margin on each item.
  • ☐ Delete the margins the gap replaces, and any clear: both a float needed; float does nothing to a flex item.
  • ☐ Add flex-wrap: wrap to any row that could run out of width.
  • ☐ A media query needs its unit: @media (max-width: 900px), never (max-width: 900), and its two closing braces.
  • ☐ Rules inside a query change only how boxes sit. Never add, remove or re-letter a word there: your output must be the same at every width.
  • ☐ Sizes in px or em, not %: CodeShare's page window is not the same size on every screen.
  • ☐ On a module step the page sits beside its checks and is already narrower than 900px, so the query is on. Your own project has no checks beside it, so the page fills the page window, and whether the query is on depends on your browser window: make it narrower if the query is off, wider if it is already on. The page window follows the browser window and cannot be dragged on its own.
  • ☐ Test at both widths, and run again at both.
