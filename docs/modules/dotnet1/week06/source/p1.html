Week 6 starts here: Juan's site has readable text and a gradient header, but his sections run into each other and his navigation is a plain line of blue links.
The box model, lists and links. Every element is a box of four layers, inside out: content (words or a picture), padding (space inside the border), the border (a line around the padding) and margin (space outside, between boxes). A border needs a width, a style and a colour. list-style-type sets each list item's marker (disc, square, upper-roman or none). A link can be styled for each state: :link, :visited, :hover, :focus and :active.
ANALOGY A gift for the class Christmas party: the gift is the content, the crumpled paper around it is padding, the box is the border, and the space between boxes on the table is margin.
