Week 04 practice tasks

.NET 1 · CSS Fundamentals and Selectors · One small task for every step, in CodeShare

How to do each task. In CodeShare, Work in code editor loads the step's sample. Run it unchanged first: Sample verified saves that check but does not complete the step. Then make the small change in Your task and Run code again. Matching the Expected task output shows Completed, saves your progress and opens the next step. Reopening a started step restores your saved edits. Spaces and line breaks count. In an output box, an indented line continues the line above it.
Weeks are linked. CodeShare opens this week only after every Week 3 task is Completed. Your module project and personal performance-task project carry forward from Week 3.
Run page and styles.css. Each step heading on pages 1–6 names its run page; the expected task output is the page text of that page. Colours, fonts and sizes are not page text, so every task changes words you can see: a new element, or CSS that changes letters (text-transform). Only Steps 1, 3 and 9 have Media checks.

MONDAY STEP 1 · Your task
