THURSDAY When the Spacing Breaks: Spacing Repairs, then Start Your Own

Know: Locate a missing semicolon or brace and an invalid spacing value in a stylesheet.

Value: Show patience and care when a whole layout breaks because of one character.

Do: Repair Juan's nav bar and broken h2 rule, then begin the personal spacing, lists and links.

Today's starting point: Browsers show no error for broken CSS: one missing character can pull a nav bar apart or switch off every rule after it.
Spacing repairs. A browser skips a value it cannot read and shows no error: a number with no unit (padding: 10), a space before the unit (1.5 em), a misspelt property (pading) or a negative padding. A missing ; skips that declaration and the next one; a missing } switches off every rule after it. When two top and bottom margins meet, only the larger one counts.
ANALOGY A row of jeepney seats held by one bolt: lose the bolt (one ; or }) and the whole row slides off its rail.
