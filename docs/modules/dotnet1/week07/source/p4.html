WEDNESDAY Pictures in a Row: An Image Gallery with Captions

Know: Describe how figure, img and figcaption build a gallery, and why captions are page text but alt is not.

Value: Respect the people and work shown in pictures by describing them honestly.

Do: Build Juan's gallery with equal picture sizes, captions and a positioned tag.

Today's starting point: Juan's gallery pictures have different sizes and plain captions.
Image gallery. A gallery is a row of figures; each figure groups an img (src, alt, width, height) with its figcaption. Float the figures left with a px width and give every picture the same size in px. Captions are page text; alt is not, but screen readers read it.
ANALOGY A school yearbook page: pictures of the same size in a row, each with its caption underneath.
