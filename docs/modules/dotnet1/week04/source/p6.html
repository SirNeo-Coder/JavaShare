Five-minute presentation

  1. Introduce yourself and your site (30 seconds).
  2. Press Run code and visit every page with your links (1 minute).
  3. Change one value in styles.css, run again and show every page change; then undo it (2 minutes).
  4. Point to one element rule, your class rule with its class attribute and your ID rule with its id (1 minute).
  5. Answer one question (30 seconds).

Prepare for these questions

  1. How are inline, internal and external CSS different?
  2. Why does one change in styles.css change every page?
  3. On one element, which wins: an ID rule or a class rule?
  4. Why may a class be used many times but an id only once?
  5. Which details did you leave out of your resume to keep it safe?
