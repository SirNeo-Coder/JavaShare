STEP 1 · index.html, styles.css · run page: index.html

Juan's Week 8 site carries forward. Flexbox arranges the boxes inside one box. You write display: flex on the container, and its children become its flex items. flex-direction: column puts them one under the other, and gap: 0.5em leaves an even space between them, with no margin to count. Juan's skills list is the container; each skill is an item. Run index.html unchanged.
