WEDNESDAY Organise Juan's Data: Table Headings, Rows and Spans

Know: Explain th, td, caption, thead and tbody and the scope, colspan and rowspan attributes and their values.

Value: Organise data clearly so that readers can compare it quickly.

Do: Build Juan's award row with colspan and a skill table with row groups and rowspan.

Today's starting point: Monday's table lists Juan's schools, but an award line or a group of skills cannot yet stretch across cells.
Table attributes. scope tells which cells a th labels: col for its column, row for its row, rowgroup for the rows of its tbody. colspan makes a cell cover more than one column and rowspan more than one row; both are whole numbers and both start at 1.
ANALOGY On a jeepney fare matrix, one heading can cover several columns, and one route can cover several rows. colspan and rowspan do the same in a table.
AttributeValuesExample
scope (on th)col, row, rowgroup, colgroupscope="col" labels its column
colspanA whole number; 1 if left outcolspan="3" covers three columns
rowspanA whole number; 1 if left outrowspan="2" covers two rows

STEP 6 · index.html

This step adds a Skill levels table. Each area is a tbody (a row group); its th has scope="rowgroup" and rowspan="2", so Computer and Art each cover two rows. This is Juan's finished Week 2 page.

New table after the Education table, before the sound greeting

  <h2>Skill levels</h2>
  <table>
    <caption>How well Juan does each skill</caption>
    <thead>
      <tr>
        <th scope="col">Area</th>
        <th scope="col">Skill</th>
        <th scope="col">Level</th>
      </tr>
    </thead>

      <tr>
        <th scope="rowgroup" rowspan="2">Computer</th>

        <td>Good</td>
      </tr>
      <tr>
        <td>Making slide presentations</td>
        <td>Very good</td>
