Discussion

  • Look at line 9. src="images/Juan_Profile.svg" has capital J and P, but the uploaded file is juan_profile.svg. Capitals count.
  • Look at line 115. src="audio/greeting.mp3" names an mp3 file, but the uploaded sound is greeting.wav.
  • Look at line 117. src="videos/juan_intro.webm" uses the folder videos, but the folder is video.
  • The page text is complete: a broken file shows no error. Only Media checks tells you: each file says failed.
  • The output ends with Media checks:, one line per picture, sound or video: whether the file loaded. Media are not page text.
