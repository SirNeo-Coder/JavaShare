MONDAY Open the Doors: Juan's Links, Second Page and Contact Form

Know: Describe the a, iframe and form elements and the href, src, label and input parts of a resume site.

Value: Value clear link text that tells readers where a link goes.

Do: Add Juan's navigation links, his projects page and a first contact form in CodeShare and run them.

Week 3 starts here: Juan's Week 2 resume is one long page: a reader cannot go to another page, see one page inside another, or send Juan a message.
Links, frames and forms. A link (a) takes the reader to another page: href names the page, and the words inside a are the link text. An iframe shows another page inside this page: src names that page. A form holds boxes where a visitor enters data: label names a box, input is a one-line box, and button sends the form.
ANALOGY At a school open house, the directory board points you to rooms (links), the office window lets you see inside without going in (a frame), and the guard's visitor logbook has labelled lines to fill in (a form).
