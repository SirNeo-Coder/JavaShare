WEDNESDAY Decorations and First Letters: ::before, ::after and ::first-letter

Know: Describe what ::before, ::after and ::first-letter add or style, and why text from content is not page text.

Value: Keep decorations from hiding or replacing the words a visitor needs.

Do: Decorate Juan's skills and motto and add a drop cap to his projects page.

Today's starting point: Juan's links, button and form boxes react to the mouse and the keyboard, but his lists and paragraphs have no decorations.
Decorations and first letters. ::before and ::after add a short symbol or mark with content. That text is decoration: it is not page text, and some screen readers skip it, so every word a visitor needs stays in the HTML. ::first-letter styles the first letter, as a large floated drop cap or with text-transform, which does change the page text.
ANALOGY A greeting card: the printed stars around the message are decoration; the message is what you read aloud.

STEP 6 · projects.html, contact.html, styles.css · run page: projects.html

A pseudo-element after a combinator. h1 + p picks the paragraph right after an h1, and ::first-letter turns its first letter into a drop cap: floated left, 2.6 times the size, in maroon. The contact page's note also comes right after its h1, so it gets one too. Run projects.html unchanged.

styles.css · a new rule (end of the file)

/* A pseudo-element after a combinator: the paragraph right after an h1 starts with a maroon drop cap */
h1 + p::first-letter {
  float: left;
  font-size: 2.6em;
  line-height: 1;
  color: #8a1c55;
  margin-right: 4px;
}

Output (page text): the same as Step 2's output; hover, focus, decorations and drop caps are not page text.
