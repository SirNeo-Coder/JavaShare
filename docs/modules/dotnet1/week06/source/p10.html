Before you style your boxes, lists and links

  • ☐ A border has a width, a style and a colour: border: 2px solid #13305c; with no style it does not show.
  • ☐ Every number has its unit right after it (10px, 0.5em); padding is never negative.
  • ☐ box-sizing: border-box keeps a box with a width that wide, padding and border included.
  • ☐ The nav is a ul of links on every page, each li on its own line in the code.
  • ☐ Link states in order: :link, :visited, :hover with :focus, :active; every colour pair at 4.5:1 (chart on page 12).
  • ☐ Sizes in px or em, not %: CodeShare's page window is not the same size on every screen.
