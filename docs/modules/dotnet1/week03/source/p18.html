Weeks are linked. CodeShare opens this week only after every Week 2 task is Completed. Your module project and personal performance-task project carry forward from Week 2.
Run page. Each step heading on pages 1–6 and in the step guide names its run page; the expected outputs are the page text of that page. Only Steps 1 and 9 have Media checks.

Before you add your pages

  • ☐ Press ＋ in your personal project; name the page with letters, numbers, - and _ and .html: projects.html, not My Projects.html.
  • ☐ Copy the same nav to the top of every page; each href is a page name exactly as in the editor tabs.
  • ☐ Your second page shows contact.html in an iframe with title, width and height.
  • ☐ Every label's for matches its box's id; every box has a name; one box is required.
  • ☐ The form has no action, and the page says it sends nowhere.

Starter pages (only for a student with no Week 2 work)

projects.html

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>My Projects</title>
</head>
<body>
  <nav><a href="index.html">Home</a> | <a href="projects.html">Projects</a> | <a href="contact.html">Contact</a></nav>
  <h1>My Projects</h1>
  <ul>
    <li>Write a school project here</li>
  </ul>
  <h2>Send me a message</h2>
  <iframe src="contact.html" title="My contact form" width="420" height="360"></iframe>
</body>
</html>

contact.html

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Contact Me</title>
</head>
<body>
  <nav><a href="index.html">Home</a> | <a href="projects.html">Projects</a> | <a href="contact.html">Contact</a></nav>
  <h1>Contact Me</h1>
  <p>This form is a prototype: it sends nowhere.</p>
  <form>
    <p>
      <label for="visitor">Your name</label><br>
      <input type="text" id="visitor" name="visitor" required>
    </p>
    <p>
      <label for="message">Message</label><br>
      <textarea id="message" name="message" rows="4"></textarea>
    </p>
    <p><button type="submit">Send message</button></p>
  </form>
</body>
</html>
