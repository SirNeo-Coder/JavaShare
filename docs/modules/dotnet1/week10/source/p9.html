Week 10 practice tasks

.NET 1 · Responsive Resume (RWD Layouts) · One small task for every step, in CodeShare

How to do each task. In CodeShare, Work in code editor loads the step's sample. Run it unchanged first: Sample verified saves that check but does not complete the step. Then make the small change in Your task and Run code again. Matching the Expected task output shows Completed, saves your progress and opens the next step. Reopening a started step restores your saved edits. Spaces and line breaks count. In an output box, an indented line continues the line above it.
Weeks are linked. CodeShare opens this week only after every Week 9 task is Completed. Your module project and personal performance-task project carry forward from Week 9.
Run page, styles.css and the template. Each step heading on pages 1–6 names its run page; its task output is the text of that page. Grids, gaps and pictures that resize move boxes only, so every task adds or changes words you can see. Steps 5 and 6 also use resume-template.css, printed on page 13. Only Steps 1, 3, 4, 7, 8 and 9 have Media checks.
