Discussion

  • Look at line 56. <table> starts a table. It closes on line 77 with </table>.
  • Look at line 57. <caption>Schools of Juan Dela Cruz</caption> is the table's title: the first line of its page text.
  • Look at line 58. <thead> holds the header row.
  • Look at line 60. <th scope="col">Level</th> is a header cell. scope="col" says it heads its column.
  • Look at line 65. <tbody> holds the data rows. It closes on line 76.
  • Look at line 66. <tr> starts one table row. Each tr is one line of the page text.
  • Look at line 67. <td>Senior high</td> is a data cell. The cells of one row sit on one line of the output, in the order you type them.
  • The output ends with Media checks:, one line per picture, sound or video: whether the file loaded. Media are not page text.
