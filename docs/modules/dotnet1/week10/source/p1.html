MONDAY Grid View: Rows, Columns and the fr Unit

Know: Explain what display: grid does to a box's children, and what grid-template-columns, fr, gap and auto-fit control.

Value: Value a layout that answers the width of the page instead of one fixed screen.

Do: Turn Juan's gallery and project cards into grids in CodeShare.

Week 10 starts here: Juan's gallery and project cards are flex rows that wrap: they fill a line and break where they run out, instead of standing in real columns.
Grid view. display: grid makes a box a grid container, and every child becomes a grid item laid out in rows and columns. grid-template-columns names the columns: repeat(2, 1fr) is two, and fr gives each a fraction of the space that is left. gap sets the space between the cells in one place. repeat(auto-fit, minmax(220px, 1fr)) lets the grid count its own columns. A grid item is a box of its own, so the output still gives it its own line.
ANALOGY A tray of pandesal: the tray is the container and the rolls are the items. The baker does not place each roll by hand; the tray's rows and columns do it, and a wider tray takes another column.
