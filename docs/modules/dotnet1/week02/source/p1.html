Value: Respect privacy and permission when choosing pictures for a resume.

Do: Add Juan's profile picture and an education table in CodeShare and run both.

Week 2 starts here: Juan's Week 1 page is all words: no picture, sound or video, and his schools would be one long sentence.
Multimedia and tables. img shows a picture, audio plays sound and video plays a video; each names its file with src. alt describes a picture for people who cannot see it. A table shows data in rows and columns: tr is a row, th a heading cell, td a data cell, caption the table's title; thead holds the heading rows and tbody the data rows.
ANALOGY A school bulletin board shows a poster with a caption under it, and a printed class schedule is a grid of rows and columns. img is the poster; a table is the grid.
