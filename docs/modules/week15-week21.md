  this module is not ready for normal classroom Run code. No in-memory substitution was made.

  before reliable sample-first rollout. Their original code and targets were deliberately retained.

  event results or menu wiring without displaying a window. The no-display message alone cannot
  complete a task. Visible GUI interaction and browser Java 8 remain unverified. A graphical

  were verified with no display, not as a complete GUI hosting feature.
- **Week 20:** missing upload arrays contain writing guidance only. Follow the original proposal
  assessment; no Java execution or automatic grading is implied.
