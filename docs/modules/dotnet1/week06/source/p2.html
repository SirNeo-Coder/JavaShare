Padding, borders, margins and box-sizing. One value sets all four sides; two values set top and bottom, then left and right; four go clockwise from the top. padding-bottom or margin-top sets one side. border-style can be solid, dashed or dotted; a border with no style shows nothing. width sets the content's width, so padding and border are added to it, unless box-sizing: border-box counts them inside. Page checks read every size in px: 0.25em of a 24px heading is 6px.
ANALOGY Seats in a jeepney: each passenger (content) has a little room on the seat (padding), the seat's edge is the border, and the space between two passengers is margin, the wider of what each one wants, not both added.
