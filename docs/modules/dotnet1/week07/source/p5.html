THURSDAY When Boxes Overlap or Float Away: Repairs, then Start Your Own

Know: Locate a missing semicolon or a misspelt value in a position or float rule.

Value: Show patience and care when one character moves a whole box.

Do: Repair Juan's ribbon and floating badges, then begin the personal gallery and positioned element.

Today's starting point: Browsers show no error for broken CSS: one missing character can leave a ribbon in the wrong place or stop badges from floating.
Overlap and float repairs. A browser skips a value it cannot read and shows no error: a missing ; skips that declaration and the next one; a misspelt value (rigth) skips only that one.
ANALOGY A poster with one pin missing slides to the wrong place; a sign written in the wrong spelling is ignored by everyone.

Problem guide

If you see…It means…Fix it by…
A badge or tag jumps to the top corner of the whole page, over the nav.Its parent has no position, so absolute is measured from the page itself.Give the parent position: relative;.
z-index changes nothing; the page check still reads your number.The box is static: z-index works only on a positioned box.Add position: relative (or absolute) to that box.
The ribbon sits in the title's line; its words share the title's line in the output.position was skipped: the ; after it is missing, or the value is misspelt.End every declaration with ;: position: absolute;.
The badges stay beside the project names; their words share the line in the output.float was skipped: its value is misspelt (rigth).Use left, right or none, spelt exactly.
The text after the gallery runs up beside the pictures.Nothing clears the floats.Give the next element clear: both;.
Practice: in styles.css, (a) delete position: relative; from the h1 rule; (b) write float: center in the .badge rule. Answers: (a) the ribbon flies to the page's top-right corner, over the nav; the output is the same; (b) the badges stay beside the project names (center is not a float value). Undo each change.
