Discussion

  • Look at line 8. <h1>Juan Dela Cruz</h1> comes before the comment, so it is the only page text in the output.
  • Look at line 9. <!-- Add my photo here in Week 2 -> starts a comment with <!--, but ends it with one dash -> instead of two -->. So the comment never ends.
  • Look at line 10. <p>Hello! I am <strong>Juan Dela Cruz</strong>, is now inside the comment, so it does not show.
  • Look at line 55. </body> is inside the comment too. Everything from line 9 to the end is hidden.
  • The browser shows no error message. It hides the text, so read the page from the top to find where the text stops.
