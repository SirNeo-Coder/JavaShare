Discussion

  • Look at line 91. <tbody> starts the first row group: Computer skills. A table may have several tbody groups.
  • Look at line 93. <th scope="rowgroup" rowspan="2">Computer</th> is the group's header cell. rowspan="2" makes it cover two rows; scope="rowgroup" says it heads the whole group.
  • Look at line 97. <tr> starts the group's second row. It has only two td cells, because Computer already covers this row.
  • Look at line 101. </tbody> ends the Computer group.
  • Look at line 104. <th scope="rowgroup" rowspan="2">Art</th> heads the second group the same way.
  • Look at line 109. <td>Painting posters</td> is Art's second skill.
  • The output ends with Media checks:, one line per picture, sound or video: whether the file loaded. Media are not page text.
