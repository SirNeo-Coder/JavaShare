MONDAY Flex Containers and Flex Items: display: flex, flex-direction and gap

Know: Explain what display: flex does to a box's children, and what flex-direction and gap control.

Value: Value a layout whose spacing is set in one place instead of on every item.

Do: Turn Juan's skills list and project list into flex containers in CodeShare.

Week 9 starts here: Juan's skills, project cards and form fields each carry their own margin, so changing the spacing means editing every rule.
Flex containers and flex items. display: flex on a box makes it a flex container, and every child becomes a flex item laid out in one direction. flex-direction: row puts the items across, column puts them one under the other, and gap sets the space between them in one place instead of a margin on each item. A flex item is a box of its own, so the output gives it its own line even when the page window shows the items side by side.
ANALOGY A jeepney bench: the passengers are the items and the bench is the container. The driver does not ask each passenger to leave a gap; the bench sets one spacing for everybody (gap), and the row either runs along the bench (row) or up the aisle (column).
