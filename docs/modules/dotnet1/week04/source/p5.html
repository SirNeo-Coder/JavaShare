Today's starting point: Browsers show no error for a broken CSS rule: the rule just does not apply, and part of the page looks plain again.
Repairing CSS. A browser skips any declaration it cannot read and shows no error. A missing semicolon joins two declarations into one unreadable declaration, so both are skipped; a missing colon loses that one declaration; a missing closing brace can stop every rule after it. A selector that does not match the HTML exactly (a misspelt class, a wrong capital letter, a missing dot) styles nothing.
ANALOGY A text message with a missing period runs two sentences together and the reader skips both; a misspelt name reaches nobody. A missing semicolon or a misspelt class does the same to a rule.

Problem guide

If you see…It means…Fix it by…
The navigation lost both its bold and its capitals.A declaration lost its semicolon, so it and the next one are skipped.Put the ; back: font-weight: bold;.
Only one property of a rule does nothing.The colon between that property and its value is missing.Write property: value;.
Every rule after one point stops working.A rule lost its closing }.Close each rule with } on its own line.
A class rule styles nothing.The class in the HTML and the selector differ (spelling, a capital letter) or the dot is missing.Copy the name exactly: class="badge" and .badge.
An ID rule styles nothing.The id and the # selector differ.Match id="form-note" and #form-note exactly.
No style from styles.css works on the page.The link line's href does not name the file exactly (style.css, Styles.css), the file is missing, or the href has no quotes.Write href="styles.css" exactly, in quotes, and check the file tab.
