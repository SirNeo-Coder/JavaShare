Today's starting point: Browsers show no error for a broken selector: one wrong letter or one space can switch a whole rule off.
Selector repairs. A browser drops a whole rule whose selector it cannot read, and shows no error: a misspelt pseudo-class or pseudo-element, or one bad selector in a comma list. A space before a colon changes the meaning: it looks for elements inside. Text from ::before comes first, so ::first-letter styles its first character.

Problem guide

If you see…It means…Fix it by…
A rule does nothing: its words keep their old letters, and no error shows.A pseudo-class or pseudo-element is misspelt (:frist-child, ::frist-letter).Spell it exactly: :first-child, ::first-letter.
A rule with several selectors does nothing at all.One selector in the comma list is invalid, so the whole rule is dropped.Repair or remove the bad selector.
.skills li :first-child matches nothing.The space means inside: it looks for a first child inside each li.No space before the colon: li:first-child.
A badge loses its capital first letter after you add ::before.The ::before text comes first, so ::first-letter styles its first character.Put the symbol in ::after, or leave it out.
The symbol does not show, and the next line of the rule does nothing.content's closing quote is missing: the browser skips that line and the next one.Close the quote: content: "★ ";
Something reacts to the mouse but not to the Tab key.It has :hover but no :focus.Add :focus to the same rule: a:hover, a:focus.
Practice: in styles.css, (a) write .badge:first-letter with one colon; (b) write .badge::first-letter, .ribbon::frist-letter; (c) leave out the closing quote in a ::before content. Answers: (a) it still works: Solo work; (b) the whole rule is dropped: solo work; (c) no symbol, and the rule's next line is skipped too; the output is the same. Undo each change.
