Discussion

  • Look at line 19. <ul> opens the Skills list.
  • Look at line 20. Typing documents has no li tags, so it is not a list item.
  • Look at line 21. Making slide presentations has no li tags either, so the browser joins both skills into one line: Typing documents Making slide presentations.
  • Look at line 25. <li>Drawing comics</li> is a correct list item in the Interests list. Compare it with lines 20 and 21.
  • Each li starts a new line of page text. Text without li inside a ul runs together.
